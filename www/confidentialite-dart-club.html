Notice de version de test

Informations préparées le 16 novembre 2026 pour la version 0.12.0-club-test · code 13. Les durées de conservation et les mentions juridiques complètes restent à finaliser avant diffusion publique. Cette notice ne constitue pas une validation Google Play.

Profils et résultats

La version de test documentée propose des invités sans compte, des profils enregistrés localement, la reprise des matchs et des statistiques de précision : simples, doubles, triples, 25 et bull. Les noms de joueurs, scores et statistiques servent au suivi des parties.

Publicité

Les notes de la version 0.12 indiquent qu’aucune publicité de test ou commerciale n’est active. Des emplacements sont préparés pour une éventuelle version ultérieure, sans affichage actuel. Le manifeste livré est décrit comme dépourvu d’initialisation automatique AdMob.

Comptes et conservation

Les fonctions décrites reposent sur des profils locaux ; aucun compte cloud n’est annoncé pour cette version. Les données restent sur le téléphone jusqu’à leur suppression. Les sauvegardes éventuelles gérées par Android dépendent des réglages du téléphone et de la configuration de l’application.

Périmètre de cette notice

Cette fiche concerne Dart Club By AJS Studio, édité par AJS Studio. Elle repose sur les notes de la version de test distribuée. L’inventaire complet des données techniques et services intégrés sera précisé avant la diffusion publique.

Effacer les données

Pour effacer entièrement les données locales, utilisez les réglages Android de l’application, rubrique Stockage, puis Effacer les données. Cette opération réinitialise les profils et statistiques : exportez auparavant les éléments que vous souhaitez conserver si votre version propose cette fonction. Pour toute difficulté, contactez AJS Studio.

Vos droits et vos demandes

Vous pouvez demander l’accès, la rectification, l’effacement ou la limitation du traitement de vos données et, lorsque les conditions s’appliquent, exercer vos droits d’opposition et de portabilité. Un consentement peut être retiré pour l’avenir sans remettre en cause les traitements antérieurs licites. Une permission Android ne remplace pas nécessairement un consentement à un usage publicitaire.

Précisez l’application et les données concernées. Si nécessaire, nous vous demanderons les éléments strictement utiles pour vérifier que vous êtes titulaire du compte. N’envoyez jamais votre mot de passe ni votre code de connexion.

Les demandes doivent recevoir une réponse dans les meilleurs délais, en principe sous un mois. Une prolongation de deux mois est possible en cas de complexité ou de demandes nombreuses, avec information dans le premier mois. Vous pouvez adresser une réclamation à la CNIL.
