Test-version notice

Information prepared on 16 November 2026 for version 0.2.0. Retention periods and the complete legal disclosures must be finalised before public distribution. This notice is not Google Play approval.

Local data

The app stores profiles, settings, saved matches and results in its local storage. This game’s data and resources are separate from Blackball.

Private matches

For a private match, both devices connect to the server selected for that session. It receives technical player and room identifiers, game commands, positions and scores. Matches are stored on the server disk; a resume token is stored on the phone. The server can see device network addresses.

Accounts and services

The reviewed version has no online user account and no Firebase or AdMob SDK in its application module. The supplied server is intended for testing and private matches; no public AJS Studio hosting is represented as active.

Retention and deletion

Profiles and saves remain on the phone until removed. Exported files remain under your control. Private-server records are separate: request their deletion from the server operator. AJS Studio cannot remotely erase files on a server you host yourself.

Private-play security

The prototype supports HTTP on a local network. This local transport is not encrypted: do not use that configuration as a public Internet service or include confidential information in player names or room codes.

Providers and transfers

When using the Google/Firebase features described on this page, these providers process information needed for the service, including IP addresses and technical connection data. A European database location does not guarantee all processing stays in Europe. See Firebase privacy and transfer information and Google’s privacy policy.
