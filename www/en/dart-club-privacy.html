Test-version notice

Information prepared on 16 November 2026 for version 0.12.0-club-test · code 13. Retention periods and the complete legal disclosures must be finalised before public distribution. This notice is not Google Play approval.

Profiles and results

The documented test version offers guests without an account, locally saved profiles, match resume and accuracy statistics for singles, doubles, triples, 25 and bull. Player names, scores and statistics support match tracking.

Advertising

Version 0.12 release notes state that neither test nor commercial ads are active. Placements are prepared for a possible later release but do not display ads now. The supplied manifest is described as having no automatic AdMob initialisation.

Accounts and retention

The described features use local profiles; no cloud account is announced for this version. Data remains on the phone until removed. Any Android-managed backups depend on phone settings and app configuration.

Scope of this notice

This page concerns Dart Club By AJS Studio, published by AJS Studio. It is based on the distributed test version’s release notes. A complete inventory of technical data and integrated services will be specified before public distribution.

Erasing data

To clear all local data, use the app’s Android settings, then Storage and Clear data. This resets profiles and statistics: first export anything you wish to keep if your version provides an export feature. Contact AJS Studio if you need help.
